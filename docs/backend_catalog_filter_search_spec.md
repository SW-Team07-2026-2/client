# 카탈로그 카테고리별 필터 · 세그먼트 · 검색 기능 요구사항 (프론트엔드 기준)

> 현재 프론트엔드 화면(사용자 클라이언트)에 구현되어 있는 **검색, 세그먼트, 정렬, 상세 필터, 새로고침, 무한 스크롤** 기능을 기준으로, 백엔드에서 지원해 주어야 하는 동작을 자연어로 정리한 문서입니다.  
> 구체적인 엔드포인트 URL 및 파라미터 네이밍은 백엔드 설계에 맞춰 정해주시면 프론트엔드에서 그대로 연동하겠습니다.

---

## 1. 공통 기능 (4개 카테고리 전체 적용)

메인 화면에는 **아티스트(Artist)**, **공연(Concert)**, **앨범(Album)**, **굿즈(Merchandise)** 4개 카테고리가 있으며, 모든 카테고리에서 아래 공통 기능을 제공합니다.

### 1-1. 피드 세그먼트 (3가지 보기 모드)
화면 상단 우측에서 사용자가 원하는 피드 기준을 하나 선택할 수 있습니다. 선택한 세그먼트는 다른 카테고리로 이동해도 그대로 유지됩니다.

1. **추천 (기본값)**
   - 사용자의 취향(팔로우한 아티스트, 관심사 등)에 맞춘 개인화 추천 목록을 보여줍니다.
2. **인기**
   - 현재 인기가 높은 순서(팔로워, 조회수, 예매/판매 등 카테고리별 인기 기준)로 목록을 보여줍니다.
3. **팔로우**
   - 로그인한 사용자가 **팔로우하고 있는 아티스트**와 관련된 항목만 모아서 보여줍니다.
   - 아티스트 탭에서는 팔로우한 아티스트 본인이, 공연·앨범·굿즈 탭에서는 내가 팔로우한 아티스트의 공연·앨범·굿즈만 필터링되어 나옵니다.

### 1-2. 팔로우 전용 정렬 (세그먼트가 '팔로우'일 때만 노출)
사용자가 세그먼트를 **팔로우**로 선택했을 때만 필터 패널 안에 정렬 선택 영역이 추가로 나타납니다. 아래 3가지 중 하나를 단일 선택할 수 있으며, 선택한 정렬 기준은 카테고리를 바꿔도 유지됩니다. (정렬 기준 유지는 프론트에서 관리하므로 백엔드는 고려하지 않아도 됨)

1. **최근 팔로우순 (기본값)**: 사용자가 가장 최근에 팔로우한 아티스트(및 해당 아티스트의 콘텐츠)가 먼저 나오도록 정렬합니다.
2. **팔로워순**: 팔로워 수가 많은 아티스트(및 해당 아티스트의 콘텐츠) 순으로 정렬합니다.
3. **업데이트순**: 최근에 새로운 콘텐츠가 등록되거나 정보가 업데이트된 순으로 정렬합니다.

*(세그먼트를 '추천'이나 '인기'로 바꾸면 팔로우 정렬은 적용되지 않습니다.)*

### 1-3. 검색
각 카테고리 헤더 좌측에 검색창이 있으며, 사용자가 키워드를 입력해 현재 보고 있는 카테고리 안에서 원하는 항목을 찾을 수 있습니다.
- 검색어가 비어 있으면 검색 조건 없이 일반 세그먼트(추천 / 인기 / 팔로우) 목록을 조회합니다.
- **세그먼트에 따른 검색 범위 (2가지 범위만 존재)**:
  - UI상 검색 모드에 진입하면 기존 **'추천'과 '인기' 세그먼트가 '전체' 하나로 합쳐져** 동작합니다. 따라서 백엔드 검색 범위는 **'전체'**와 **'팔로우'** 두 가지만 구분하면 됩니다.
  1. **전체 검색 (추천 · 인기 세그먼트 상태에서 검색 시)**: 현재 카테고리의 **전체 데이터**를 대상으로 키워드를 검색합니다.
  2. **팔로우 내 검색 (팔로우 세그먼트 상태에서 검색 시)**: 로그인한 사용자가 **팔로우한 아티스트(및 해당 아티스트의 공연·앨범·굿즈) 범위 안에서만** 키워드를 검색합니다. *(팔로우 전용 정렬 기준도 그대로 적용)*
- **필터 결합**: 검색 중에도 카테고리별 상세 필터(장르, 지역, 진행 현황, 유형, 형태, 가격대 등)는 기존과 동일하게 **AND 조건**으로 함께 적용되어야 합니다.

### 1-4. 필터 조합 및 무한 스크롤 · 새로고침
- **복합 조건 결합 방식**:
  - **같은 필터 항목 안에서 여러 개를 고른 경우(다중 선택)**: 선택한 항목 중 **하나라도 해당하면** 결과에 포함됩니다(OR 조건).  
    *(예: 장르에서 '인디 록'과 '슈게이즈'를 동시에 선택하면 둘 중 하나에 속하는 항목 모두 표시)*
  - **서로 다른 필터 항목 · 검색어 · 세그먼트를 함께 고른 경우**: 선택한 조건을 **모두 만족하는** 항목만 표시됩니다(AND 조건).  
    *(예: 공연에서 '팔로우' 세그먼트 + 지역 '서울' + 진행 현황 '판매중'을 고르면, 내가 팔로우한 아티스트의 서울 지역 판매중 공연만 표시)*
- **카테고리별 필터 상태 기억**: 각 카테고리의 필터는 독립적으로 동작하며, 다른 탭을 다녀와도 이전 선택 상태가 유지됩니다. 초기화 버튼을 누르면 현재 카테고리의 필터 조건이 모두 해제됩니다. (해당 기능은 프론트쪽에서 관리. 백엔드는 고려하지 않아도 됨)
- **페이지네이션(무한 스크롤)**: 목록 하단에 도달하면 다음 묶음 데이터를 순차적으로 불러올 수 있어야 하며, 더 불러올 데이터가 남아 있는지 여부도 함께 내려주어야 합니다.
- **새로고침 버튼**: 사용자가 새로고침 버튼을 누르면 현재 선택된 검색어·필터·세그먼트 조건을 유지한 채 첫 페이지부터 최신 목록을 다시 불러옵니다. *(특히 '추천' 탭에서는 새로고침 시 새로운 추천 순서가 내려오거나 최신 상태로 갱신되는 동작이 자연스럽습니다.)*

## 2. 카테고리별 기능 상세

### 2-1. 아티스트 (Artist)
* **검색 대상**: 아티스트명(한글/영문 등)으로 아티스트를 검색합니다.
* **세그먼트**: 추천 / 인기 / 팔로우 (팔로우 선택 시 전용 정렬 3종 적용)
* **상세 필터**:
  1. **장르 (다중 선택)** — 총 23개 항목 중 원하는 만큼 선택 가능(기존 문서 활용)
     - 인디 록(`INDIE_ROCK`), 얼터너티브(`ALTERNATIVE`), 개러지(`GARAGE`), 펑크(`PUNK`), 하드코어(`HARDCORE`), 이모(`EMO`), 메탈(`METAL`), 포스트 록(`POST_ROCK`), 슈게이즈(`SHOEGAZE`), 사이키델릭(`PSYCHEDELIC`), 인디 팝(`INDIE_POP`), 드림 팝(`DREAM_POP`), 신스 팝(`SYNTH_POP`), 시티 팝(`CITY_POP`), 포크(`FOLK`), 일렉트로닉(`ELECTRONIC`), R&B/소울(`RNB_SOUL`), 힙합(`HIPHOP`), 재즈(`JAZZ`), 블루스(`BLUES`), 펑크(Funk)(`FUNK`), 스카/레게(`SKA_REGGAE`), 기타(`ETC`)

---

### 2-2. 공연 (Concert)
* **검색 대상**: 공연명, 출연 아티스트명, 공연장명 등으로 공연을 검색합니다.
* **세그먼트**: 추천 / 인기 / 팔로우 (팔로우 선택 시 전용 정렬 3종 적용)
* **상세 필터** (총 4개 항목, 모두 다중 선택 가능):
  1. **진행 현황 (다중 선택)** — 3개 항목
     - 판매전 / 판매중 / 판매종료
  2. **공연 유형 (다중 선택)** — 2개 항목
     - 단독(`SOLO`) / 페스티벌(`FESTIVAL`)
  3. **지역 (다중 선택)** — 전국 17개 시·도
     - 수도권: 경기(`GYEONGGI`), 서울(`SEOUL`), 인천(`INCHEON`)
     - 강원: 강원(`GANGWON`)
     - 충청: 충북(`CHUNGBUK`), 충남(`CHUNGNAM`), 대전(`DAEJEON`), 세종(`SEJONG`)
     - 전라: 전북(`JEONBUK`), 전남(`JEONNAM`), 광주(`GWANGJU`)
     - 경상: 경북(`GYEONGBUK`), 경남(`GYEONGNAM`), 부산(`BUSAN`), 대구(`DAEGU`), 울산(`ULSAN`)
     - 제주: 제주(`JEJU`)
     - *(화면에서는 도 단위와 소속 광역·특별시를 권역별로 묶어 보여주지만, 실제 선택과 필터링은 각 시·도 개별 단위로 이루어집니다.)*
  4. **장르 (다중 선택)** — 아티스트와 동일한 23개 장르 목록

---

### 2-3. 앨범 (Album — 음반 & LP)
* **검색 대상**: 앨범명, 상품명, 아티스트명 등으로 음반을 검색합니다.
* **세그먼트**: 추천 / 인기 / 팔로우 (팔로우 선택 시 전용 정렬 3종 적용)
* **상세 필터** (총 2개 항목):
  1. **형태 (다중 선택)** — 3개 항목
     - LP(`LP`), CD(`CD`), 카세트(`CASSETTE`)
  2. **가격대 (범위 슬라이더)**
     - 최소 `0원`부터 최대 `150,000원`까지 `5,000원` 단위로 최소 금액과 최대 금액을 지정할 수 있습니다.
     - **전체 범위(`0원 ~ 15만원 이상`)**: 가격 필터를 적용하지 않고 전체 가격대의 상품을 보여줍니다.
     - **최대 금액이 끝(`150,000원`)에 걸쳐 있는 경우**: 화면에 **'15만원 이상'**으로 표시되며, **상한 제한 없이 최소 금액 이상인 모든 상품**이 나와야 합니다. *(예: `30,000원 ~ 15만원 이상` 선택 시 30,000원 이상 전체 조회)*
     - **그 외 범위 지정 시**: 선택한 최소 금액 이상, 최대 금액 이하에 해당하는 상품만 조회합니다. *(예: `20,000원 ~ 80,000원`)*

---

### 2-4. 굿즈 (Merchandise)
* **검색 대상**: 굿즈명, 아티스트명 등으로 굿즈를 검색합니다.
* **세그먼트**: 추천 / 인기 / 팔로우 (팔로우 선택 시 전용 정렬 3종 적용)
* **상세 필터** (총 2개 항목):
  1. **형태 (다중 선택)** — 9개 항목 (기존 문서 활용)
     - 티셔츠(`TSHIRT`), 아우터(`OUTER`), 키링(`KEYRING`), 피크(`PICK`), 머플러(`MUFFLER`), 스카프(`SCARF`), 가방(`BAG`), 모자(`HAT`), 기타(`ETC`)
  2. **가격대 (범위 슬라이더)**
     - 앨범과 동일한 규칙 적용 (`0원 ~ 150,000원`, `5,000원` 단위, 최대치 도달 시 **'15만원 이상'** 상한 무제한 처리)

## 4. 추가 보완 기준 (확정)

1. **공연 진행 현황 필터**: 예매 시간(판매 상태) 기준으로 필터링합니다.
2. **공연 장르 필터**: 공연 자체 장르뿐만 아니라 **출연 아티스트들의 장르까지 포함**해 매칭합니다. (이미 공연 장르 자체가 아티스트들의 장르를 전부 포괄하고 있다면 문제 없음)
3. **앨범 · 굿즈 가격대 필터**: 상품의 **대표가(옵션 최저가)** 기준으로 필터링합니다.
